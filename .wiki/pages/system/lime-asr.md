# 职责

`lime-asr` 只做三件事：以子进程调用 `whisper-cli`、解析其 JSON 词级时间戳、把词重组成句子；解码、模型发现与下载都不在本 crate [[cite:crates/lime-asr/src/lib.rs:L1-L12]]。

# 公开接口

`WhisperCli { exe, model, threads, language }` 描述一次转写所需的全部参数 [[cite:crates/lime-asr/src/lib.rs:L22-L28]]，由 `WhisperCli::new` 构造 [[cite:crates/lime-asr/src/lib.rs:L76-L83]]。`transcribe_words` 返回 `Vec<Word>` 并支持取消与进度回调 [[cite:crates/lime-asr/src/lib.rs:L87-L93]]。辅助 API 包括 `pipeline_fingerprint(_s)` [[cite:crates/lime-asr/src/lib.rs:L172-L200]]、`parse_words_json` [[cite:crates/lime-asr/src/lib.rs:L216-L216]]、`group_sentences` [[cite:crates/lime-asr/src/lib.rs:L249-L249]]、`anchors_from_words` [[cite:crates/lime-asr/src/lib.rs:L288-L288]] 与 `blank_spans` [[cite:crates/lime-asr/src/lib.rs:L360-L360]]。

# 内部机制

## 子进程调用

参数顺序固定为 `-m <model> -f <wav> -l <language> -t <threads> -oj -ml 1 -sow -mc 0 -pp -of <out_base>`；stdout 丢弃、stderr 管道读取 [[cite:crates/lime-asr/src/lib.rs:L102-L123]]。`-ml 1 -sow` 提供 10 ms 级逐词时间戳，`-mc 0` 关闭跨窗口上下文以根治长静音上的整句重复幻觉 [[cite:crates/lime-asr/src/lib.rs:L3-L11]]。

Windows 下额外设置 `CREATE_NO_WINDOW` 与 `BELOW_NORMAL_PRIORITY_CLASS`，避免弹窗并降低后台转写对前台的干扰 [[cite:crates/lime-asr/src/lib.rs:L124-L132]]。输出 JSON 路径通过追加 `.json` 得到（而不是替换扩展名，否则 `.asr` 会被吃掉），写入前先删除旧文件 [[cite:crates/lime-asr/src/lib.rs:L94-L101]]。

## 进度与取消

stderr 按行读取；发现取消标志时直接 `kill` 子进程并返回 `Error::Asr("cancelled")` [[cite:crates/lime-asr/src/lib.rs:L137-L148]]。`parse_progress` 提取包含 `progress` 的行中 `=` 之后的数字并除以 100，得到 0–1 的进度 [[cite:crates/lime-asr/src/lib.rs:L202-L213]]。

## JSON 解析

要求顶层存在 `transcription` 数组；每项读取 `/offsets/from`（默认 0）、`/offsets/to`（默认等于 from）与 `text`（默认空串），生成 `Word { start_ms, end_ms, text }`。坏 JSON 返回 `Error::Asr("json: …")`，缺字段返回 `Error::Asr("missing `transcription`")` [[cite:crates/lime-asr/src/lib.rs:L216-L245]]。

## 错误映射

启动失败返回 `spawn <exe>: …`；Windows 退出码 `0xC0000135`/`-1073741515` 被映射为缺少 VC++ 2015-2022 运行库的提示；其他非零退出码返回 `whisper-cli exited with <status>`；读取输出失败返回 `read <path>: …` [[cite:crates/lime-asr/src/lib.rs:L133-L164]]。

## 句子重组

`group_sentences` 在四种情况下断句：暂停达到 `gap_s`、词数超过 `max_words`、时间跨度超过 `max_ms`、或遇到 `.`/`?`/`!`/`。` 终止符；空文本词被丢弃 [[cite:crates/lime-asr/src/lib.rs:L247-L284]]。

## 指纹与默认值

参数指纹是字面量 `asr-pipeline/2|ml=1|sow=1|mc=0` 加 `|lang=<lang>`；完整指纹再追加 `|model=<文件名>:<字节数>`，没有模型时写 `model=none` [[cite:crates/lime-asr/src/lib.rs:L172-L200]]。默认语言为 `en` [[cite:crates/lime-asr/src/lib.rs:L30-L32]]，线程数在核数 ≤2 时用全部核心，否则用核数减一，`available_parallelism` 失败时回退 2 [[cite:crates/lime-asr/src/lib.rs:L39-L53]]。

# 已知边界

- 模型与可执行文件的定位/下载在应用层完成，不在本 crate [[cite:crates/lime-app/src/paths.rs:L48-L57]]；GUI 中的下载逻辑也独立于转写驱动 [[cite:crates/lime-app/src/gui.rs:L462-L581]]。
- 指纹使用模型文件名与字节数，而不是内容哈希 [[cite:crates/lime-asr/src/lib.rs:L191-L191]]。
- 取消只会在 stderr 有新行到达时被观察到，长时间无输出的子进程不能立即中止 [[cite:crates/lime-asr/src/lib.rs:L139-L147]]。
- 现有测试只覆盖指纹、JSON offsets 与线程策略，句子重组和锚点启发式尚无直接测试 [[cite:crates/lime-asr/src/lib.rs:L368-L423]]。
