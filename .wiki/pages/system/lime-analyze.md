# 职责

`lime-analyze` 是以 DSP 为主的结构分析器：能量包络 → 精确静音 → 语音岛 → 间隙分类 → 叮咚标记 → 两级章节骨架；阈值全部在四个真实素材上标定 [[cite:crates/lime-analyze/src/lib.rs:L1-L7]]。

# 公开接口

crate 暴露 `chime/repeat/snap` 三个子模块，并从根模块重新导出包络、结构检测、叮咚检测、边界收集、章节构建与重复材料合并等入口 [[cite:crates/lime-analyze/src/lib.rs:L11-L20]]。顶层入口包括 `energy_envelope`/`EnvelopeAccumulator` [[cite:crates/lime-analyze/src/lib.rs:L86-L90]]、`detect_structure` [[cite:crates/lime-analyze/src/lib.rs:L199-L204]]、`collect_boundaries` [[cite:crates/lime-analyze/src/lib.rs:L316-L320]]、`build_chapters` [[cite:crates/lime-analyze/src/lib.rs:L415-L421]]，以及 `merge_repeated_materials(_with)` [[cite:crates/lime-analyze/src/lib.rs:L20-L20]]。

# 内部机制

## 包络与时间轴

`AnalyzeParams` 的默认值为：20 ms 帧、5 ms 帧移、-55 dBFS 静音阈值、0.35 s 句子间隙、2.0 s 题目间隙、8.0 s 材料间隙、0.4 s 吸附半径 [[cite:crates/lime-analyze/src/lib.rs:L40-L53]]。包络按帧计算均方根 dB（`10·log10(mean_sq+1e-20)`），以流式累加器实现 O(窗口) 内存，并保证分块输入与整段输入结果一致 [[cite:crates/lime-analyze/src/lib.rs:L96-L104]]。

帧移必须使用采样精确换算后的真实毫秒值；44.1 kHz 下 5 ms 对应 221 个样本（5.0113 ms），若使用名义值会在 932 秒处累积约 2 秒漂移 [[cite:crates/lime-analyze/src/lib.rs:L161-L164]]。因此索引与时间的互转统一走该真实 hop [[cite:crates/lime-analyze/src/lib.rs:L194-L204]]。

## 间隙与语音岛

间隙按降序阈值阶梯分类：≥8 s 为材料间隙，≥2 s 为题目间隙，≥0.35 s 为句子间隙，更短则丢弃 [[cite:crates/lime-analyze/src/lib.rs:L182-L192]]。数字静音（样本恰为 0.0）按最小长度检测为连续段 [[cite:crates/lime-analyze/src/lib.rs:L247-L270]]，但 `detect_structure` 返回的 `has_digital_silence` 固定为 `false`，需由调用方设置 [[cite:crates/lime-analyze/src/lib.rs:L238-L244]]。

任一侧短于 `MIN_QUESTION_MS = 400` 的题目会被跳过并折叠进前一题，避免产生 0–40 ms 的碎片章节 [[cite:crates/lime-analyze/src/lib.rs:L65-L70]]；该不变量在构建章节时有专门处理 [[cite:crates/lime-analyze/src/lib.rs:L499-L503]]。

## 边界与章节

边界置信度是固定阶梯：间隙 + 叮咚 0.98，仅间隙 0.85，仅叮咚为 `0.75·max(conf,0.4)+0.2`；只有置信度达到 `min_confidence` 的叮咚才参与 [[cite:crates/lime-analyze/src/lib.rs:L322-L328]]。候选边界按 `next_start_ms` 排序，相距小于 1.5 s 时合并，取较早内容结束、较晚下一段开始，来源取并集、置信度取最大 [[cite:crates/lime-analyze/src/lib.rs:L383-L399]]。

章节构建把首个材料强制命名为“引言”，其余为“材料 N”（除非锚点提供标题），区间裁剪到首尾语音，并始终经过 `normalize_chapters` 规范为“材料 → 题目”顺序 [[cite:crates/lime-analyze/src/lib.rs:L424-L443]]。章节范围与规范化逻辑集中在此 [[cite:crates/lime-analyze/src/lib.rs:L448-L479]]，最终输出统一规范化 [[cite:crates/lime-analyze/src/lib.rs:L536-L538]]。

## 叮咚检测

默认频率为叮 2578 Hz、咚 2039 Hz，Q=18、20 ms 带通窗、120 ms 上升、高于 ±5 s 中位数 10 dB；衰减窗 1.2 s 内下降 14 dB 且不得回升 4 dB [[cite:crates/lime-analyze/src/chime.rs:L100-L128]]。

音调纯度闸门要求带内峰值至少比峰值时刻的宽带 RMS 高 `tonality_db`（-8 dB）；比较窗口是峰值附近 -40 ms/+200 ms，而不是起始点 [[cite:crates/lime-analyze/src/chime.rs:L260-L273]]。前导静音闸门还要求起始前 2 秒（排除最后 300 ms）绝对电平 ≤ -65 dB 且相对峰值低 12 dB；上升、中位数、不回升、衰减、前导与音调纯度全部通过才接受 [[cite:crates/lime-analyze/src/chime.rs:L274-L292]]。

配对时在叮之后 0.25–1.2 s 内寻找咚，按最大电平与衰减测试选择；置信度为 `clamp(1 - |Δ-0.59|/0.30, 0, 1)`，内容起点直接取咚的时刻 [[cite:crates/lime-analyze/src/chime.rs:L371-L386]]。

## 重复材料合并

重复检测是章节级而非句子重建：对每个材料收集中点落在其范围内、由 ASCII 字母数字组成的句子词元，先做 O(n+m) 多重集重叠预筛，再用 Dice 系数 `2·LCS/(|a|+|b|)` ≥ 0.65、至少 8 个词元且长度比不超过 2.5 判定重复 [[cite:crates/lime-analyze/src/repeat.rs:L164-L179]]。参数默认值集中定义 [[cite:crates/lime-analyze/src/repeat.rs:L33-L41]]，预筛实现在同文件 [[cite:crates/lime-analyze/src/repeat.rs:L181-L221]]。

合并时把重复段折叠为一个材料，范围取最早开始到最晚结束，每一遍降级为标题“第 N 遍”的题目；只要存在锁定材料或子项就放弃合并，结果再次规范化并保持幂等 [[cite:crates/lime-analyze/src/repeat.rs:L116-L161]]。

## 时间戳吸附

默认吸附路径都调用保守的 `align_words_safe`：只把 `start_ms == 0` 且首个语音岛超过 500 ms 的词移到岛起点，然后强制单调，不会把词搬进其他语音岛 [[cite:crates/lime-analyze/src/snap.rs:L43-L75]]。更激进的 `clamp_into_speech` 只服务仿射/比例/分段路径，把短于 1500 ms 的词推出静音并重新单调化 [[cite:crates/lime-analyze/src/snap.rs:L162-L205]]。
