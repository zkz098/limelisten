# 职责

`lime-app` 是唯一直接写 UI 的 crate：同一份分析/转写能力既服务 Slint 图形界面，也服务 `--analyze`、`--assert`、`--transcribe` 等无界面命令 [[cite:crates/lime-app/src/main.rs:L1-L15]]。

# 公开接口与启动

`main.rs` 手工解析参数并用 `env_logger` 初始化日志（默认 `warn`），没有识别到参数时落到 `gui::run()` [[cite:crates/lime-app/src/main.rs:L75-L82]]。参数分派覆盖 `--analyze`、`--assert`、`--transcribe`、`--limed`、`--show-limed`、`--chapters`、`--benchmark/--bench`、`--playtest`、`--tools`、`--help`，以及把“第一个参数是现存文件”解释为打开 GUI [[cite:crates/lime-app/src/main.rs:L82-L148]]。

# CLI 子命令

`cmd_analyze` 流式解码并打印静音、叮咚与两级章节报告；`cmd_assert` 运行同一组断言，任一失败即 `process::exit(1)` [[cite:crates/lime-app/src/cli.rs:L422-L458]]，断言入口在同文件 [[cite:crates/lime-app/src/cli.rs:L462-L485]]。

`cmd_transcribe` 先调用一次 `analyze_and_export_wav`，再执行转写并打印原始与吸附后的词时间戳对比 [[cite:crates/lime-app/src/cli.rs:L625-L639]]。`cmd_export_limed` 在音频同目录生成 `<stem>.limed` [[cite:crates/lime-app/src/cli.rs:L822-L885]]。

`cmd_chapters` 打开 `data/library.db`，按规范路径（失败则按文件名）定位媒体并打印章节树；`cmd_show_limed` 加载并规范化 `.limed` 后输出 [[cite:crates/lime-app/src/cli.rs:L778-L819]]，后者入口在同文件 [[cite:crates/lime-app/src/cli.rs:L888-L895]]。

GUI 复用 CLI 的同一套管线：`gui.rs` 直接导入 `analyze_and_export_wav`、`transcribe` 与 `assign_sentences_to_chapters` [[cite:crates/lime-app/src/gui.rs:L10-L10]]，CLI 文档也说明二者共享分析函数 [[cite:crates/lime-app/src/cli.rs:L1-L1]]。

# 便携路径

`product_root()` 的优先级是：可执行文件目录（当同级存在 `tools/` 或 `models/`）→ 开发项目根（当存在 `Cargo.toml`）→ 可执行文件目录 [[cite:crates/lime-app/src/paths.rs:L22-L45]]。

Whisper 工具搜索首选 `tools/whisper/{cuda,cublas12.4,cublas,vulkan,blas,cpu}/Release/whisper-cli.exe`，随后是开发态 `.tools/...` [[cite:crates/lime-app/src/paths.rs:L48-L69]]；模型依次从 `models/`、项目 `models/`、`.tools/models/` 查找 [[cite:crates/lime-app/src/paths.rs:L72-L108]]。

默认模型按机器规格选择：≤4 核或 ≤8 GB 内存优先 small/base，否则使用 turbo q5_0；四个可下载规格带有 URL 与精确字节数 [[cite:crates/lime-app/src/paths.rs:L164-L197]]，规格表在同文件 [[cite:crates/lime-app/src/paths.rs:L251-L296]]。

运行数据固定在 `<product_root>/data`，缓存为 `data/cache`；`prune_cache` 默认上限 2 GB（可用 `LIMELISTEN_CACHE_LIMIT_MB` 覆盖），按最旧优先删除 `.wav`/`.json`，并跳过 5 分钟内新文件 [[cite:crates/lime-app/src/paths.rs:L376-L404]]，删除策略在同文件 [[cite:crates/lime-app/src/paths.rs:L389-L454]]。

# GUI 架构

启动时 `run_with` 创建 `MainWindow`、打开 `<data>/library.db`、用 `Rc<RefCell<Store>>` 共享、启动 `ProgressSaver`、在后台线程清理缓存、建立 `Msg` 通道、设置版本/GitHub/许可证属性、刷新列表，最后可选加载命令行传入的文件 [[cite:crates/lime-app/src/gui.rs:L778-L815]]。

`GuiState` 持有当前路径与媒体 id、`AnalysisCore`、句子、懒加载的 `Engine`、速度/循环/自动暂停开关、`busy` 原子标志、下载状态、媒体列表、练习与进度保存器 [[cite:crates/lime-app/src/gui.rs:L84-L123]]；`Msg` 承载状态文本、分析与转写结果、基准/下载进度与文件夹扫描结果 [[cite:crates/lime-app/src/gui.rs:L31-L72]]。

UI 线程靠重复触发的 Slint `Timer` 用 `try_recv` 排空跨线程通道，更新位置、字幕与进度，并在空闲时 200 ms、播放时 50 ms 重新定时 [[cite:crates/lime-app/src/gui.rs:L2280-L2295]]；事件泵的初始化与结束处理分布在同文件 [[cite:crates/lime-app/src/gui.rs:L2067-L2084]] 与 [[cite:crates/lime-app/src/gui.rs:L2381-L2393]]。

后台分析用 `busy.swap` 防止并发，降低线程优先级后调用 `analyze_and_export_wav`，完成后发送 `AnalyzeDone`/`Error` [[cite:crates/lime-app/src/gui.rs:L2820-L2856]]；转写使用同样的后台线程模式并发送 `TranscribeDone` [[cite:crates/lime-app/src/gui.rs:L917-L975]]。

播放引擎在首次播放时通过 `Engine::new_at` 懒创建；UI 发送有界通道命令，并通过 `shared()` 轮询 `pos_ms`、`playing`、`underruns` 与 `take_reached_stop` [[cite:crates/lime-app/src/gui.rs:L1048-L1087]]，`Shared` 的访问接口定义在音频 crate [[cite:crates/lime-audio/src/engine.rs:L99-L108]]。

数据库常规访问在 UI 线程同步进行，只有进度写入排队到 `lime-progress` 线程，并在 `Drop` 时 join [[cite:crates/lime-app/src/gui.rs:L780-L787]]，线程实现位于存储 crate [[cite:crates/lime-store/src/lib.rs:L878-L928]]。

# 打开顺序

加载媒体时先检查匹配的 `.limed`，再读取 SQLite 章节与字幕并恢复上次章节与位置；只有两者都未命中才在后台启动分析 [[cite:crates/lime-app/src/gui.rs:L2522-L2555]]。缓存命中与恢复分支在同文件 [[cite:crates/lime-app/src/gui.rs:L2635-L2641]]，分析兜底 [[cite:crates/lime-app/src/gui.rs:L2720-L2732]]。

# 已知边界

- xtask 帮助文本宣传的 `check/build/test` 没有独立分支，除 `dist` 外参数原样转发给 cargo [[cite:xtask/src/main.rs:L13-L19]]。
- `product_root()` 可能与 `exe_dir()` 相同，导致候选路径重复 [[cite:crates/lime-app/src/paths.rs:L22-L45]]。
- 目录访问器会顺带创建目录，因此仅运行 `--tools` 也可能生成 `tools/` 与 `models/` [[cite:crates/lime-app/src/paths.rs:L376-L380]]。
- `--playtest` 实现在 `main.rs` 而非 `cli.rs` [[cite:crates/lime-app/src/main.rs:L152-L234]]。
